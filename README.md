# Seven Dragon

> 放置型城市經營 × 自動遠征 × 英雄軍隊 × 世界地圖 × 國家陣營

目前專案處於 **企劃／MVP 規劃階段**。

## 核心概念

玩家經營一座城市，而不是直接操作單一角色。

**城市建設 → 資源生產 → 建築升級 → 英雄／部隊形成遠征隊 → 自動採集／戰鬥／探索 → 帶回成果 → 城市進一步發展**

長期目標是從小村莊逐步發展成大型城市、領地，最後成為世界上的強大國家。

## 開發原則

1. 先完成可玩的核心 Loop，再增加內容。
2. 優先資料驅動，讓建築、資源、兵種、陣營等內容容易擴充。
3. Idle 遊戲應該降低操作量，而不是降低策略性。
4. 重要設計決策必須同步記錄到文件。
5. MVP 不提前實作 PvP、國戰、課金等大型系統。
