# Seven Dragon

> 有煙火氣的城市模擬 × 資源生產鏈 × Travian 式策略 × 戰鬥與領土

目前專案處於 **企劃／MVP 規劃階段**。

## 核心概念

Seven Dragon 不是單純的增量／放置遊戲。玩家主要經營的是一座「活著的城市」。

村民會實際出現在城市中、走向建築、取得職業、前往資源區工作、攜帶資源返回倉庫，再離開／消失。隨著建築與生產鏈增加，城市會逐漸變得繁忙、熱鬧、有煙火氣。

核心循環：

`村民生成 → 選擇工作 → 移動 → 取得職業 → 採集／生產 → 搬運 → 回城 → 資源入庫 → 村民結束生命週期 → 新村民生成`

資源再投入：

`資源 → 工具／建築 → 更多工作 → 更複雜生產鏈 → 戰鬥單位 → 擴張`

### 設計目標

- **看城市，而不是只看數字。**
- 數值負責平衡，畫面負責呈現成長與熱鬧。
- 建築不是單純的「+10% 生產」，而是提供新的工作與生產能力。
- 村民、工人、士兵、運輸單位等應盡量共享一致的單位／物流邏輯。
- 後期加入 Travian 式資源、軍隊、領土與戰略，但不讓遊戲退化成純數字表格。

## 開發原則

1. 先完成「村民真的在工作」的核心 Loop，再增加大型系統。
2. 優先資料驅動，讓建築、資源、職業、工具、兵種容易擴充。
3. Idle 降低操作量，但不能降低世界的可見性與策略性。
4. 避免無止境膨脹的數字；成長應主要體現在新能力、新建築、新單位與城市活力。
5. 重要設計決策同步記錄到文件。
6. MVP 不提前實作 PvP、國戰、課金等大型系統。
